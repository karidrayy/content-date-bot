# CONTENT DATE ❤️ — Telegram-бот-предложка

## Возможности
- Принимает текст, фото, видео, документы и другие сообщения.
- Отправляет их указанным администраторам.
- Администратор отвечает через Reply на уведомление или скопированное сообщение.
- Токен и ID администраторов задаются переменными окружения.

## Локальный запуск
1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. Скопируйте токен.
3. Узнайте Telegram ID администраторов, например через [@userinfobot](https://t.me/userinfobot).
4. Установите Python 3.12+ и зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
   В Windows: `.venv\\Scripts\\activate`
5. Задайте переменные окружения:
   ```bash
   export BOT_TOKEN="токен_от_BotFather"
   export ADMIN_IDS="123456789,987654321"
   python bot.py
   ```
   Не публикуйте токен и не коммитьте файл `.env`.

## Деплой
Загрузите файлы в GitHub-репозиторий и подключите репозиторий к хостингу, который разрешает постоянно работающие worker-процессы. Укажите переменные `BOT_TOKEN` и `ADMIN_IDS`, команда запуска — `python bot.py`.

Бот использует Telegram long polling, поэтому собственный домен и HTTPS не требуются. Проверьте условия бесплатного тарифа перед деплоем: доступность бесплатных worker-процессов и правила сна/лимитов у платформ меняются. Сопоставьте тариф с официальной документацией хостинга.
